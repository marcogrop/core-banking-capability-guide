# Document Status and Intended Use

The Canonical Banking Capability Model (CBCM) is a canonical domain reference and architecture aid. It is suitable for custom platform definition, capability mapping, bounded-context design, requirements discovery, specification extraction, API and event modeling, implementation planning, architecture governance, vendor or solution evaluation, and training. It is not legal, regulatory, accounting, or product advice, and it does not claim to reproduce every feature or implementation detail of Apache Fineract or any commercial core banking product.

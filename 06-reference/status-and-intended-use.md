# Document Status and Intended Use

This guide is a canonical domain reference and an architecture aid. It is suitable for capability mapping, bounded-context design, requirements discovery, specification extraction, API and event modeling, implementation planning, and training. It is not legal, regulatory, accounting, or product advice, and it does not claim to reproduce every feature or implementation detail of Apache Fineract or any commercial core banking product.

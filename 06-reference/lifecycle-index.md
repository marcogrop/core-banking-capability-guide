# Lifecycle Index

Representative lifecycle summaries collected from the capability chapters.

| Capability | Typical lifecycle |
|---|---|
| [Customer Management](../01-business-capabilities/01-customer-management.md) | Prospective → Submitted → Active → Inactive or Suspended → Transferred → Closed |
| [Organization Management](../01-business-capabilities/02-organization-management.md) | Defined → Activated → Reorganized or Reassigned → Deactivated |
| [Identity & Security](../05-platform-capabilities/03-identity-and-security.md) | Invited or Provisioned → Active → Locked → Suspended → Disabled → Archived |
| [Product Catalog](../01-business-capabilities/04-product-catalog.md) | Draft → Reviewed → Approved → Active → Suspended for New Sales → Retired |
| [Loan Management](../01-business-capabilities/05-loan-management.md) | Submitted → Approved → Disbursed → Active → Delinquent → Rescheduled or Re-aged → Written Off → Foreclosed or Early Settled → Closed |
| [Savings Management](../01-business-capabilities/06-savings-management.md) | Submitted → Approved → Active → Restricted or Blocked → Dormant → Closed |
| [Deposit Management](../01-business-capabilities/07-deposit-management.md) | Submitted → Approved → Awaiting Funding → Active → Matured → Renewed → Prematurely Closed → Closed |
| [Share Management](../01-business-capabilities/08-share-management.md) | Applied → Approved → Active → Partially Redeemed → Fully Redeemed → Closed |
| [Accounting](../03-financial-infrastructure/09-accounting.md) | Business Event Received → Rule Resolved → Entry Generated → Validated → Posted → Reversed |
| [Payment Processing](../03-financial-infrastructure/10-payment-processing.md) | Initiated → Validated → Authorized → Executed → Clearing → Settled → Rejected → Returned → Reversed |
| [Interest Engine](../02-policy-capabilities/11-interest-engine.md) | Configured → Effective → Accruing → Capitalized or Posted → Recalculated → Superseded |
| [Fee Engine](../02-policy-capabilities/12-fee-engine.md) | Defined → Assessed → Due → Partially Paid → Paid → Waived → Refunded → Capitalized → Reversed |
| [Delinquency Management](../02-policy-capabilities/13-delinquency-management.md) | Current → Early Arrears → Intermediate Arrears → Severe Arrears → Collections → Cured → Written Off |
| [Collateral Management](../02-policy-capabilities/14-collateral-management.md) | Registered → Eligible → Pledged → Monitored and Revalued → Released → Substituted → Enforced or Liquidated → Retired |
| [General Ledger](../03-financial-infrastructure/15-general-ledger.md) | Defined → Active → Blocked for Posting → Inactive |
| [Reporting](../04-information-capabilities/16-reporting.md) | Defined → Approved → Scheduled or Requested → Running → Generated → Distributed → Archived or Failed |
| [Workflow & Approval](../05-platform-capabilities/17-workflow-and-approval.md) | Started → In Progress → Waiting → Escalated → Approved → Rejected → Cancelled → Completed |
| [Notification](../05-platform-capabilities/18-notification.md) | Requested → Rendered → Queued → Sent → Delivered → Failed → Retried → Suppressed → Expired |
| [Integration](../05-platform-capabilities/19-integration.md) | Received or Created → Validated → Transformed → Routed → Acknowledged → Retried → Failed → Dead-Lettered → Reprocessed |
| [Batch Processing](../05-platform-capabilities/20-batch-processing.md) | Scheduled → Starting → Running → Paused → Completed → Failed → Restarting → Cancelled |
| [Configuration](../05-platform-capabilities/21-configuration.md) | Draft → Validated → Approved → Scheduled → Effective → Superseded → Rolled Back → Retired |
| [Administration](../05-platform-capabilities/22-administration.md) | Provisioning → Active → Restricted or Maintenance → Degraded → Suspended → Decommissioned |
| [Audit](../05-platform-capabilities/23-audit.md) | Captured → Sealed → Indexed → Retained → Placed on Hold → Exported → Disposed according to Policy |
| [Platform Services](../05-platform-capabilities/24-platform-services.md) | Requested → Validated → Executed → Published or Indexed → Superseded or Archived |

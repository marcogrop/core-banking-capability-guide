# Core Banking Glossary

| **Term**                     | **Definition**                                                                                                                                      |
|------------------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------|
| **Aggregate**                | A consistency boundary with one aggregate root controlling changes to its internal entities.                                                        |
| **Authoritative record**     | The capability and data set permitted to change a specific business fact.                                                                           |
| **Business date**            | The institution’s operational date, which may differ from the wall-clock date.                                                                      |
| **Business event**           | An immutable statement that a meaningful, committed domain change occurred.                                                                         |
| **Command**                  | A request to perform a state-changing business operation.                                                                                           |
| **Contract**                 | A customer-specific financial agreement created from product terms and subsequent approved changes.                                                 |
| **Days Past Due (DPD)**      | Number of days an unpaid obligation has remained overdue under the applicable policy.                                                               |
| **Effective dating**         | Modeling when a version, rate, rule, or assignment becomes and ceases to be applicable.                                                             |
| **General Ledger**           | Institution-wide books of account containing posted journal lines and balances.                                                                     |
| **Idempotency**              | Property that repeated processing of the same request does not duplicate its business effect.                                                       |
| **Journal entry**            | Balanced set of debit and credit lines representing an accounting consequence.                                                                      |
| **Ledger balance**           | Posted accounting or subledger amount before availability restrictions or pending items.                                                            |
| **Available balance**        | Amount currently available after holds, restrictions, limits, and applicable settlement rules.                                                      |
| **Product**                  | Reusable template of commercial, policy, accounting, and operational terms.                                                                         |
| **Projection or read model** | Derived data optimized for queries and reporting, not authoritative state changes.                                                                  |
| **Reversal**                 | Explicit compensating operation that preserves the original record and negates its effect.                                                          |
| **Subledger**                | Detailed operational ledger for a product domain, such as loan or savings transactions.                                                             |
| **Value date**               | Date from which a financial transaction affects interest or economic value.                                                                         |
| **Workflow instance**        | A running, version-bound execution of a business process definition.                                                                                |
| **Write-off**                | Recognition that an exposure is considered a loss for accounting or operational purposes; it does not necessarily extinguish legal recovery rights. |
